# Launcher wallpapers

The fifteen entries in `SOURCES.json` each have a background JPEG and a thumbnail. Three registered material JPEGs per image (`field-clear`, `field-blur`, `field-frost`) live in `../materials/`. All derived images retain the source photograph's terms.

Photo pages, authors and licence observations are in [asset sources](../../../docs/asset-sources.md). Generation instructions are in [asset generation](../../../docs/assets.md). Full-size originals remain outside the repository.
